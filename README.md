# Research Data Management and Analysis (InDepth)

Open course materials on research data management (RDM) and statistical modeling, created by Daniel Manrique-Castaño for InDepth Data Science Consulting. Built with [Quarto](https://quarto.org/) and published at <https://daniel-manrique.quarto.pub/rdm-datascience/>. Companion files are on the Open Science Framework: <https://osf.io/cngt3/>.

## Modules

- **Setup**: R, RStudio, Git and GitHub (`R-studioRepositories.qmd`)
- **Research data management** (`RDM/`): introduction, organizing data and tables, working with images, sharing data
- **Principles of statistical modeling** (`Modeling/`): handling tables, exploratory analysis, fitting models, diagnostics (in progress)

Downloadable resources (TIER 4.0 dataset template, FIJI script, example image README, codebook vignette) are in `resources/`.

## Relationship to RDM_DataTraining

This repository supersedes [daniel-manrique/RDM_DataTraining](https://github.com/daniel-manrique/RDM_DataTraining), which holds the original reveal.js slide decks (July–August 2024) from which the RDM module was developed. Its resources were copied here. The slides on depositing data (including FRDR) have not been ported yet.
